# اقرأها – نسخة التشكيل والحركات والصور

هذه النسخة تضيف:
- كلمات وجمل بالتشكيل.
- تدريبات اختيارية: قراءة بالتشكيل، الفتحة، الضمة، الكسرة، السكون، الشدة.
- صورة اختيارية لكل كلمة/جملة.
- تقييم المتصفح الأساسي يبقى متاحًا.
- دعم اختياري لمحرك **Azure Speech Pronunciation Assessment** للحصول على تقييم صوتي على مستوى الفونيمات.

## مهم جدًا حول دقة الحركات
التعرف الصوتي العادي في Chrome/Edge غالبًا يعيد النص العربي بدون الحركات القصيرة، لذلك **لا يمكن اعتباره حكمًا دقيقًا على الفتحة والضمة والكسرة والسكون والشدة**.

للتقييم الصوتي الدقيق، يجب تفعيل Azure Speech Pronunciation Assessment على الخادم. توثيق Microsoft يوضح أن تقييم النطق يعطي درجات على مستوى الفونيم، وأن `ar-SA` مدعومة لتقييم النطق. 

### تفعيل التقييم الدقيق في Render
في إعدادات Web Service أضيفي Environment Variables:
- `AZURE_SPEECH_KEY` = مفتاح Azure Speech
- `AZURE_SPEECH_REGION` = منطقة مورد Azure، مثل `eastus`

لا تضعي المفتاح داخل ملفات الموقع أو GitHub.

بعد إضافة المتغيرات وإعادة النشر، نقطة `/api/pronunciation` تصبح جاهزة لاستقبال تسجيل WAV وتحليله. النسخة الحالية من واجهة الطالب ما زالت تستخدم التعرف المحلي كمسار أساسي؛ دمج التسجيل الكامل مع خدمة Azure يحتاج تفعيل المحرك أولًا.

## نشر النسخة
Build Command:
`npm install`

Start Command:
`npm start`

يستمع الخادم على `0.0.0.0` ويستخدم `PORT`.

## ملاحظة الإنتاج
للاستخدام المدرسي الحقيقي، يفضّل نقل بيانات الطلاب من `data/db.json` إلى قاعدة بيانات دائمة مثل PostgreSQL.
