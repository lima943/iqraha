# اقرأها
موقع تعليمي كامل مبدئي: طالب + قراءة صوتية + مستويات + حفظ تقدم + لوحة معلم وإدارة محتوى.

التشغيل:
1. ثبّت Node.js 18 أو أحدث.
2. شغّل: `node server.js`
3. افتح: `http://localhost:3000`

حساب المعلم الافتراضي:
username: teacher
password: ChangeMe123!

غيّر كلمة المرور قبل النشر عبر:
TEACHER_USER و TEACHER_PASSWORD

مهم: للتشغيل على أجهزة الطلاب عبر الإنترنت استخدم HTTPS. هذه نسخة MVP؛ قبل الاستخدام المدرسي النهائي يفضل PostgreSQL وحسابات وصلاحيات ونسخ احتياطي وحماية بيانات الأطفال، وتحسين دقة تقييم النطق العربي.


### ملاحظة الصوت
تم تحسين زر «اسمع» لاختيار صوت عربي متاح في Chrome/Edge تلقائيًا، مع معالجة أفضل لتحميل الأصوات.


## النشر على Render
- Build Command: `npm install`
- Start Command: `npm start`
- المشروع يستخدم `process.env.PORT` ويستمع على `0.0.0.0`.
- رابط Render سيكون HTTPS، وهذا مناسب لاستخدام الميكروفون في المتصفح.
- ملاحظة: ملف `data/db.json` تخزين محلي، لذلك هذه النسخة مناسبة للتجربة العامة، وليست تخزينًا دائمًا للإنتاج. للاستخدام المدرسي الفعلي نربط قاعدة بيانات PostgreSQL.
